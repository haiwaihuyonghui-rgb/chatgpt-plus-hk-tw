## 方法一：官網訂閱

- **怎麼做：** ChatGPT：頭像 → Upgrade Plan；Claude：設定 → 帳單 / 升級。綁卡付款。
- **條件：** OpenAI 定價頁寫明 Go、Plus、Pro 可用「任何主要信用卡」購買（[定價頁](https://openai.com/chatgpt/pricing/)）；Claude 定價頁付款方式寫的是信用卡。
- **優點：** 最正規，官方售後和退款；Claude Pro 可以年付。
- **缺點 / 風險：** 卡片沒開海外交易、3D 驗證失敗、帳單地址不符都會被拒，見 [taiwan.md](taiwan.md)；香港、澳門不在支援清單。

## 方法二：App Store / Google Play 內購

- **怎麼做：** 在 ChatGPT 或 Claude App 裡升級，用商店綁定的付款方式扣款。
- **價格：** 以當地商店顯示為準；Anthropic 官方寫明手機端價格可能因平台不同而不同。
- **注意：** 訂閱由蘋果 / Google 管理，取消、退款要到商店辦；網頁和 App 各訂一份會被重複扣費（[OpenAI 官方說明](https://help.openai.com/en/articles/20001043-how-do-i-avoid-being-charged-twice-if-i-subscribe-to-chatgpt-on-ios-android-and-the-web)、[Anthropic 帳單 FAQ](https://support.claude.com/en/articles/8325618-paid-plan-billing-faqs)）。

## 方法三：禮品卡

- **ChatGPT 官方禮品卡：** 目前只在美國銷售和兌換，要人在美國、帳號以美元計費；只能在網頁 chatgpt.com/redeem 兌換，不能用於 App 內購（[官方說明](https://help.openai.com/en/articles/20001491-buying-and-redeeming-openai-gift-cards)）。台灣、香港用戶基本用不了。
- **Claude 贈送訂閱：** 官方寫明目前暫停購買（[官方說明](https://support.claude.com/en/articles/12938627-how-to-gift-a-claude-subscription)）。
- 網上遠低於面值的禮品卡要小心，常見是盜刷來的。

## 方法四：代購 / 代儲（代付）

- **是什麼：** 賣家替你付款，把會員開到**你自己的帳號**上。
- **優點：** 不用自己的卡；不會從你的卡自動續費。
- **缺點：** 不是官方渠道，不能找官方退款；售後全靠賣家。
- **風險：** 賣家不靠譜、索要密碼導致盜號；帳號被停用的誘因多在使用這一側，一般不在保固範圍。
- **挑賣家看 6 點：** 開在自己帳號、不要密碼和驗證碼、到帳時間說得清、失敗怎麼退、中途掉會員管不管、售後找得到人。

不建議買共享帳號 / 合租：多人共用容易觸發風控，聊天記錄別人看得到。
